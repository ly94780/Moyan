# 墨页 · Markdown 阅读编辑器

面向 Windows 的离线 Markdown 桌面应用。当前版本 0.2.4，支持系统双击打开、单实例多文件标签、标签右键菜单、拖拽打开，以及阅读、编辑和实时分屏预览。

界面采用一行 38px 紧凑工具栏和一行 30px 文件标签，移除重复标题与面板说明条。常用文件操作以小图标显示，悬停可查看说明和快捷键；字号设置只影响正文或编辑器。

## 本地开发

```powershell
npm ci
npm run dev
```

环境基线为 Node.js 22 LTS，依赖的实际版本由 `package-lock.json` 锁定。Electron 首次安装需要下载桌面运行时，应用运行时无需联网。

若默认下载源连接较慢，可在当前 PowerShell 会话中设置 `$env:ELECTRON_MIRROR='https://npmmirror.com/mirrors/electron/'` 后再安装依赖；打包工具镜像对应 `$env:ELECTRON_BUILDER_BINARIES_MIRROR='https://npmmirror.com/mirrors/electron-builder-binaries/'`。

## 检查与打包

```powershell
npm run lint
npm run format:check
npm run typecheck
npm test
npm run test:e2e
npm run dist:win
```

`npm run build` 生成 `out/`，之后可执行 `npm start`。当前 Windows 安装包输出到 `release/0.2.4/`，免安装目录位于 `release/0.2.4/win-unpacked/`。旧版产物保留在原位置。

可直接启动 `release/0.2.4/win-unpacked/墨页.exe` 体验，保留整个目录即可，无需安装 Node.js。完整验证此独立程序可在 PowerShell 中设置 `$env:MOYAN_EXECUTABLE=(Resolve-Path 'release/0.2.4/win-unpacked/墨页.exe').Path`，再执行 `npx playwright test`；结束后执行 `Remove-Item Env:MOYAN_EXECUTABLE` 恢复对源码生产构建的测试。

Windows 上执行 `node scripts/test-installer.mjs` 可用 NSIS 验证安装关联逻辑；测试只创建随机名称的应用注册并清理，不改变默认程序。首次运行可能需要下载与打包相同的 NSIS 工具。

## 使用

- 将墨页设为 `.md` / `.markdown` 默认打开方式后，双击文件会直接读取正文；应用已启动时在当前窗口增加标签，最小化时恢复窗口，不新开一个应用窗口。重复打开同一个文件会切回原标签，保留未保存修改和撤销记录。
- 安装包注册 Markdown 文件打开能力，同时更新 Windows 已有的同名 `墨页.exe` 应用注册，让旧免安装版的默认打开选择使用新安装路径。默认程序仍由用户在 Windows“打开方式”中选择。升级时先退出旧版；单独移动或更换免安装目录时，需要重新选择该目录的 `墨页.exe`。
- 启动初始化、恢复草稿确认或设置弹窗期间收到的文件会排队，完成后继续打开；读取失败会显示提示并保留已打开文件。命令行也可使用 `墨页.exe "文档甲.md" "文档乙.markdown"` 打开多个文件。
- 点击“打开”可多选 `.md` 或 `.markdown` 文件，也可从资源管理器将一个或多个文件拖入窗口（包括编辑区）。
- 每个文件在顶部显示为标签，点击切换，点击右侧 × 关闭。同一个文件重复打开或拖入时会激活已有标签，保留其未保存内容；同名不同目录的文件各自保留，悬停查看完整路径。
- 右键文件标签可选择“打开所在文件夹”“关闭其他标签”“关闭所有标签”。打开文件夹会在资源管理器中定位该文件；未落盘的新文档禁用此项，只有一个标签时禁用“关闭其他标签”。聚焦标签后也可按 Shift+F10 或菜单键打开菜单。
- “关闭其他标签”保留右键点中的文件。批量关闭只询问真正修改过的文件；中途取消、保存失败或另存为取消时，不移除任何目标标签。此前已经明确确认完成的保存或重新载入仍有效。
- 每个标签独立保留内容、撤销记录、光标、滚动位置和显示模式；仅活动标签使用编辑器视图，后台标签不持续运行预览任务。
- 顶部切换阅读、编辑和分屏；分屏中可拖动中线，也可选中中线后用方向键调整。
- 左侧目录可以跳转标题；代码块支持复制；设置中调整主题、字号和网络图片。
- `Ctrl+S` 保存当前文件，`Ctrl+Shift+S` 另存为，`Ctrl+W` 关闭当前标签，`Ctrl+Tab` / `Ctrl+Shift+Tab` 前后切换文件。
- `Ctrl+F` / `Ctrl+H` 打开查找替换，`Ctrl+Shift+P` 切换显示模式。聚焦顶部文件标签时可用左右方向键或 Home / End 切换。
- 未保存标记按真实内容判断。只进入编辑模式、移动光标或查找不会产生修改；撤销或手动还原至最近保存内容后，标记消失，关闭时不询问保存。空白新文档也可直接关闭。
- 只有实际修改的文件关闭时才询问；取消关闭会保留内容。打开、新建和切换标签不触发其他文件的保存询问。退出时逐个检查有修改的文件，中途取消会保留所有标签。
- 文件在外部被修改时，保存会提供取消、另存为、重新载入和覆盖选项。
- 编辑期间约每 2 秒将各标签的改动写入恢复草稿，不会自动改写原文件。异常退出后可一起恢复多个文件；保存或关闭一个标签不影响其他草稿。最后约 2 秒的输入可能未落盘；可读取旧版单文档草稿。

## 支持与限制

支持 UTF-8（含 BOM）以及 LF/CRLF；不支持的编码会拒绝打开。原始 HTML 按文本展示；公式、Mermaid、文件夹工作区和云同步尚未包含。

较大文档在后台生成预览，期间可以切换编辑与保存。极长的连续段落可能需要数秒完成预览，实际测量见验收记录。

本地图片仅支持文档目录及子目录内的 PNG、JPEG、GIF、WebP；新文档需先保存，才能以文档目录解析相对图片。网络图片默认关闭，可在设置中开启。网页链接使用系统浏览器打开。

保存前按文件内容校验外部修改。首版没有跨进程文件锁，检查与替换之间存在极短的竞争窗口。不建议多个程序同时保存同一文件。
