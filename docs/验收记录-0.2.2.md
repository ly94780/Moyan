# 墨页 0.2.2 验收记录

日期：2026-11-21。本次增加文件标签右键菜单；紧凑布局与原有文件行为的历史记录见 [0.2.1](验收记录-0.2.1.md)及 [0.2.0](验收记录-0.2.0.md)。

## 新增行为

- 文件标签右键使用 Electron 原生菜单，包含“打开所在文件夹”“关闭其他标签”“关闭所有标签”；支持菜单键与 Shift+F10。
- 操作针对被右键点中的标签，不会把当前文件当成其他标签的目标。文件夹定位由主进程按文档标识查找路径，调用系统资源管理器定位文件；未落盘新文档禁用此项。
- 只有一个标签时禁用“关闭其他标签”。关闭其他后激活保留的标签，关闭全部后回到欢迎页。
- 批量关闭先确认整个目标组，再移除标签。没有实际修改的文件不询问；取消、保存失败或另存为取消时不移除目标标签，也不清除其未保存内容和草稿。
- 已经明确完成的保存或外部重新载入不会因后续取消而撤回。确认期间如果先前已确认的内容再次变化，会重新确认。

## 验证结果

| 检查                                | 结果                                               |
| ----------------------------------- | -------------------------------------------------- |
| TypeScript strict、ESLint、Prettier | 通过                                               |
| 单元测试                            | 26 项通过，新增 6 项批量关闭保护用例               |
| 生产构建桌面场景                    | 15 项场景通过；其中长文场景单独前台复测通过        |
| Windows 0.2.2 打包与独立程序        | NSIS 安装包生成成功；独立程序 4 项右键菜单场景通过 |

新增单元覆盖：无修改全关、保留后台右键目标与其草稿、中途取消、后续保存失败、外部重载后的文档标识变化，以及确认后继续修改时重新确认。

新增桌面覆盖：

1. 三个菜单名称与启用状态正确；未命名和单标签禁用正确；后台文件定位路径正确；Shift+F10 可触发菜单。
2. 关闭其他保留右键点中的后台标签；无修改时静默关闭所有并返回欢迎页。
3. 批量关闭中途取消，所有目标正文与恢复草稿仍保留，磁盘原文不变。
4. 后续保存失败或另存为取消时保留全部目标标签；此前成功保存的文件仍然有效。

自动化使用实际标签、IPC、文档管理与文件读写。为了避免打开系统资源管理器窗口，测试替换了 `shell.showItemInFolder` 并检查其接收的真实文件路径。原生 `Menu.popup` 在自动化中被替换以读取实际菜单结构并触发实际菜单项回调；系统菜单绘制未做屏幕级自动验证。原生文件选择与保存询问同样使用固定返回值。

初轮并行构建时，既有两万行连续段落用例发生超时。单元用例只检查末尾完整性，因此为该用例单独设置 20 秒等待预算；桌面性能用例保持原有等待上限，在前台单独复测通过，首次完整预览约 16.9 秒。应用的 Markdown 解析实现未修改，仍保留极长连续段落后台排版较慢这一已知限制，不将缓存切换速度表述为首次解析速度。

- 当前版本 0.2.2，输出目录 `release/0.2.2/`。
- 安装包 `Moyan-0.2.2-Setup.exe`；免安装程序 `win-unpacked/墨页.exe`，须保留整个目录。
- 未实际执行安装与卸载，旧版产物保留在原位置。
- 文件恢复、中文输入法、系统剪贴板、屏幕阅读器、真实磁盘写满和文件锁定等既有人工检查项继续保留，见历史记录。
- 没有新增运行依赖；顶部仍为两行紧凑布局。
