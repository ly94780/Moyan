# 墨页 0.2.3 验收记录

日期：2026-11-21。本次修复系统默认打开 Markdown 时只显示主页的问题，并实现单实例文件转交。标签右键菜单、紧凑布局等历史记录见 [0.2.2](验收记录-0.2.2.md)、[0.2.1](验收记录-0.2.1.md)及 [0.2.0](验收记录-0.2.0.md)。

## 修复与行为

- 首次启动读取 Windows 传入的 `.md` / `.markdown` 文件路径，直接显示文件正文；支持多个文件、中文、空格、特殊字符和相对路径。
- 在读取应用数据与创建窗口前获取 Electron 单实例锁。后续进程只转交文件并退出，已有进程恢复最小化窗口并激活新标签。未传文件时只激活已有窗口。
- 路径按发送进程的工作目录解析，通过 `additionalData` 转交，避免 Chromium 改动参数顺序；只接收受支持的文件路径。
- 重复打开同一文件激活原标签，不从磁盘覆盖未保存正文，保留撤销历史。不同目录同名文件仍各占一个标签。
- 外部请求保存在主进程队列；界面就绪、草稿恢复确认及当前操作完成后才读取。设置弹窗期间也保留请求，关闭设置后继续处理。无常驻轮询，无新增运行依赖。
- 读取错误在界面提示，不移除现有标签；后续请求仍可继续打开。外部文件复用已有编码校验、大文件确认和受控资源处理。
- 安装包包含 `.md` 与 `.markdown` 文件关联配置；默认打开方式由用户在 Windows 中选择。

Electron 行为依据：[Windows 启动文件参数](https://www.electronjs.org/docs/latest/api/app#event-open-file-macos)、[单实例锁与转交](https://www.electronjs.org/docs/latest/api/app#apprequestsingleinstancelockadditionaldata)。安装配置依据本项目锁定版本的 electron-builder `FileAssociation` 类型与 NSIS 关联模板。

原生进程验证覆盖：

1. 首次启动读取中文空格路径和多个文件，支持大小写扩展名。
2. 运行中打开新文件恢复最小化窗口；以不同路径大小写重复打开时激活已有标签，保留修改和撤销历史，磁盘原文不变。
3. 两个第二进程连续从不同工作目录传入相同的相对文件名，正确生成两个标签；无文件启动不新增窗口或标签。
4. 先持久化真实修改草稿，再以文件参数启动应用；恢复确认前收到的新请求不丢失，恢复内容不被磁盘原文覆盖。
5. 设置期间暂缓打开；混合有效和不存在的文件时显示错误且保留已有内容；后续请求仍可激活已有标签。

原有标签回归包括多选、拖入、独立保存、无修改静默关闭、多草稿恢复、外部冲突、光标与滚动保留，以及右键批量关闭取消或失败保护。此次未重复测量与修改无关的极长连续段落预览性能，历史限制仍见 0.2.2 记录。

## 交付与限制

- 版本 0.2.3，输出目录 `release/0.2.3/`；安装包 `Moyan-0.2.3-Setup.exe`，免安装程序 `win-unpacked/墨页.exe`，须保留整个目录。
- 不修改本机默认打开方式，不安装或卸载用户已有版本；系统默认程序选择与真实安装后资源管理器双击仍需用户确认。本次通过实际 exe 文件参数与实际第二进程验证相同的应用接收链路。
- 升级前退出旧版。已关联旧免安装目录时，需把 Windows 默认打开方式重新指向新版 `墨页.exe`；新代码不能替代仍由 Windows 启动的旧版可执行文件。
- 既有中文输入法、屏幕阅读器、真实磁盘写满、文件锁定及跨进程保存竞争窗口等限制继续保留，见历史记录。
